# 成长因子有效性初检

**日期**：2026-08-02
**代码版本**：见本次提交
**结论**：**当前复合因子未通过有效性检验，不具备可用性。**

---

## 一、检验设置

| 项 | 设置 |
|---|---|
| 样本 | 81 只 A 股（按当前总市值分层取样，剔除 ST 与北交所） |
| 区间 | 2019-01-02 ~ 2026-07-31（90 个月度调仓） |
| 行情 | Yahoo Finance（东财限流降级），不复权 |
| 财务 | 东财 datacenter，按 `NOTICE_DATE` 做 PIT 对齐 |
| 策略 | 复合打分取 Top 15，等权，月度调仓，T+1 成交 |
| 成本 | 佣金 0.025% + 印花税 0.1%（卖出）+ 过户费 + 冲击成本 0.1% |
| 参照 | 等权持有全部 81 只样本股 |

---

## 二、收益表现

| 指标 | 因子策略 | 参照组 | 差异 |
|---|---:|---:|---:|
| 年化收益 | 40.15% | 31.79% | **+8.37%** |
| 年化波动 | 32.00% | 22.38% | +9.62% |
| **夏普比率** | **1.21** | **1.35** | **-0.14** |
| **最大回撤** | **-36.90%** | **-25.42%** | **-11.48%** |
| Calmar | 1.09 | 1.25 | -0.16 |
| 胜率 | 50.90% | 51.77% | -0.87% |
| 平均换手 | 14.0% | 5.0% | +9.0% |

---

## 三、核心判断：超额收益是风险补偿，不是 alpha

年化多出 8.37% 看起来是好消息，但**风险调整后表现更差**：

- 夏普比率 1.21 < 参照组 1.35
- 最大回撤 -36.90%，比参照组深 11.48 个百分点
- Calmar 1.09 < 1.25
- 胜率甚至略低于参照组

也就是说，这 8.37% 是靠多承担 9.62% 的波动换来的，且换手率高出近两倍（额外成本）。
**在风险调整口径下，这个因子没有创造价值。**

---

## 四、分组单调性检验（决定性证据）

样本 5,758 个观测（股票 × 调仓期），按复合分数五等分，统计下一调仓期收益：

| 分组 | 平均收益 | 标准差 | 样本数 |
|---|---:|---:|---:|
| Q1（最低分） | 1.55% | 11.65% | 1152 |
| Q2 | 1.82% | 13.35% | 1151 |
| Q3 | 3.04% | 14.23% | 1152 |
| Q4 | 4.01% | 15.74% | 1151 |
| Q5（最高分） | 3.44% | 16.44% | 1152 |

**Q5-Q1 收益差 +1.89%，但不单调 —— Q5 反而低于 Q4。**

宪章第二条要求分组单调性作为因子有效的核心证据。此处 Q4→Q5 出现反转，
说明分数与收益之间不存在稳定的单调关系，最高分组并不是最优选择。

### 一个更值得注意的现象

标准差随分数单调递增：11.65% → 13.35% → 14.23% → 15.74% → 16.44%。

**分数越高，波动越大，且这个关系比收益关系干净得多。**

这提示当前的"成长因子"很可能主要在加载**波动率/beta**，而非真正的成长质量。
高分组收益更高，是因为它们本来就是高风险股票，在 2019-2026 这段整体上涨的
区间里自然涨得更多。这与"选出优质成长股"是两回事。

---

## 五、本次检验自身的缺陷

以下缺陷会**系统性高估**收益，因此上述 40% 年化本身就不可信：

1. **选样偏差最严重**：样本按 *2026 年 8 月的* 总市值选取，然后回测到 2019 年。
   等于先知道谁活到了今天且长成了大市值，再回头买它们。这一条足以让绝对收益失去意义。
2. **无退市股**：历史上归零的公司完全缺席。
3. **未处理涨跌停**：一字板实际无法成交，回测按可成交处理。
4. **不复权行情**：Yahoo 降级数据为不复权口径，除权日产生虚假跌幅。
5. **估值维度完全缺失**：财务表不含 PE/PB，`value` 因子块覆盖率 0%，
   实际打分只有成长与质量两个维度（权重已归一化为 0.562 / 0.437）。
6. **无样本内外划分**：权重为初始假设，未做参数稳健性检验。

绝对收益不可信，但**相对比较仍有参考价值** —— 策略组与参照组使用同一套有偏样本，
夏普与回撤的相对劣势不会因为样本偏差而反转。

---

## 六、下一步

按优先级：

1. **补齐估值维度**：用价格面板 + PIT 每股收益自行计算历史 PE/PB/PEG，
   而非依赖当期快照。这是当前最大的功能缺口。
2. **消除选样偏差**：股票池改为按每个调仓日的**历史**市值与上市状态动态构建，
   并补入退市股。
3. **波动率中性化**：既然分数与波动强相关，应在打分后对波动率做中性化处理，
   再重新检验分组单调性，确认是否还剩下真实的 alpha。
4. **换用东财前复权行情**：限流问题需通过降低请求频率或增加缓存解决。
5. 单因子逐个检验，找出哪些维度真正有效，而非直接用复合分数。

在第 1、2、3 项完成并重新通过分组单调性检验之前，本系统不输出选股结论。
